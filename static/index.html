Help / FAQ

        

          How do I run the Windows app without a command window?
          
Extract the Windows-x64 ZIP and double-click FrameworkDistiller-v0.5.5.exe. The portable app includes its own runtime, starts the local study service, and opens your browser; no Command Prompt needs to stay open. Use Folders · type a path → Quit desktop app to stop it. Your library is stored separately under your Windows user-data folder or the folder you choose.

          
For a stable Start-menu and taskbar launcher, run Install-FrameworkDistiller.ps1 from the extracted ZIP for your Windows account, then pin Framework Distiller from Start. This launcher starts the service even after a reboot. The header's Install as app button uses Edge's prompt when available; otherwise it shows the manual Edge menu and installed-app instructions. An Edge shortcut opens the study page but cannot start the service by itself. If the service is closed, its offline page can hand off to the installed Windows launcher.

        

        

          How do I pull a document from a web link?
          
Open Add a document. Enter a title, version, publication date, and a direct public HTTPS document URL on an approved NIST, Bank of England, FCA, NCSC, IIA, or OWASP host. Add a publisher SHA-256 if you have one, then choose Pull official link. The app downloads only after that click, pins the bytes it received, and opens the imported document in source order.

          
A general webpage, login page, query-string link, redirected off-host URL, or unsupported format may be refused. If a publisher’s public link will not pull, download the document yourself and use Add selected file; the local import is hash-pinned but does not claim the supplied URL served those exact bytes.

        

        

          Which file types can I import locally?
          
PDF, EPUB, DOCX, ODT, PPTX, RTF, Markdown, plain text, and HTML. Scanned PDFs without a text layer and images may not yield readable text. The app refuses files over its size or extraction limits instead of claiming complete coverage.

        

        

          Where are my documents and notes stored?
          
On this device. On Windows, Folders · type a path lets you type separate absolute paths for the library and import inbox; switching folders does not move or delete the old library. Use Import all listed for that inbox, or Choose a folder to import to pick files without saving its path. The browser cannot disclose a folder's full device path, so a persistent inbox path must be typed. On Android, the working library stays in app-private storage; use the system picker for one file or a bounded folder import, and for exports.

        

        

          What does “AI interpretation” mean?
          
It is a model’s study aid, not the authoritative framework wording, an audit finding, or proof of competence. Different providers may answer the same excerpt differently, and a short excerpt may not support an audit conclusion. Check the answer against the pinned source text and request additional evidence before making a real audit judgement.

        

        

          How do the key points, mind maps and custom questions work?
          
The six action buttons cover file, chapter and page key points or maps. The clickable document overview covers the source-order structure of the imported file. Offline output extracts headings and key sentences; AI mode uses only the bounded excerpts in the preview. For a deeper question, choose page, chapter or sampled-file scope under Ask your own question. Neither a map nor a summary proves complete understanding; explain the idea back in your own words and check the pinned source.

        

        

          When is document text sent to an AI provider?
          
Never during import or offline study. AI is off until you add your own key. Test connection sends a fixed harmless prompt without document text. A reader action sends only the exact bounded source text and instruction shown in the preview after you press Send. Keys stay in this app process’s memory and are excluded from exports; use Forget key when finished.

        

        

          How does email sharing work?
          
Open a document page, expand Share a thought or source snippet by email, type a thought and/or choose a short selection from that page, then review the exact draft. The app opens your email client; you choose the recipient and decide whether to send. It does not attach a whole book, send email itself, or store the draft. Keep copyright, employer confidentiality, and personal data in mind.

        

        

          Can I sync my Windows and Android libraries through Vidatta?
          
Not yet. Current libraries are device-local. A future owner-approved sync must be tested for authentication, conflicts, offline use, file rights and key exclusion before connecting either app to Vidatta. Email sharing is not library sync.
